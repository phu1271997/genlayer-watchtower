# Agent Categories

- `DEFI_TRADING`: checks slippage tolerance, position sizing, leverage, and asset allowlists
- `DEFI_YIELD`: checks protocol allowlists, pool audit posture, and unrealistic APY chasing
- `SOCIAL_MEDIA`: checks PII leaks, spam patterns, and brand voice consistency
- `DAO_TREASURY`: checks signer count, vote thresholds, and recipient allowlists
- `CONTENT_GEN`: checks copyright, hate speech, misinformation, and attribution posture
- `TOOLING`: checks downstream API terms, rate-limit abuse, and privileged automation drift
- `OTHER`: generic fiduciary review
